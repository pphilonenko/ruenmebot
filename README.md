RuenmeBot - Бот-администратор школы английского языка c AI Grok-3
Этот бот взаимодействует с пользователями, обучая их английскому языку, зарегистрированные пользователи ruenme.com дополнительно видят информацию о своих уроках в школе. Необходим премиум-аккаунт в Телеграм.

## Основные функции:
- Отвечает на вопросы учеников с помощью Grok AI.
- Сохраняет историю диалогов в базе MySQL (таблица `chat_history`).
- Поддерживает команды `/start`, `/help` и текстовые сообщения.
- Асинхронная обработка через `aiohttp` и `aiomysql`.
- Пересылает в Телеграм и на Емайл в школу сообщения с признаками обращения, просьбы, отзыва, жалобы.
- Ответы на запросы учеников о ценах на услуги.
- Вывод прайс-листа по запросу с группировкой по преподавателям и предметам.
- Поддержка синонимов и различных форм запросов.

## Технологии
- **Язык**: Python 3.9
- **Фреймворки**: python-telegram-bot 20.7, aiohttp 3.9.1, aiomysql 0.2.0
- **API**: Telegram Bot API, Grok API
- **База данных**: MySQL (***, таблица `chat_history`)
- **Сервер**: CentOS 8, Apache для вебхуков

Установка

Создай бота в Телеграм, получи вебхук.
Клонируй репозиторий:git clone git@github.com:pphilonenko/ruenmebot.git
Установи зависимости:pip install -r requirements.txt
Настрой конфигурацию (переименуй config.example.py в config.py и заполни параметры).
Запусти бота:python3.9 main.py
